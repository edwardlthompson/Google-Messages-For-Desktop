## Pitch

A FOSS Electron wrapper for Google Messages for web on Windows, macOS, and Linux: native window, tray unread badge, OS notifications, and sms:/tel:/im: protocol compose without UA spoofing.

See the canonical product [README.md](../../README.md) for install, donate, and protocol details.
