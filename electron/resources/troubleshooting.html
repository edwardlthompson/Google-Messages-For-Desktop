Troubleshooting

Toasts, tray, and taskbar

New-message toasts use the operating system’s notification API, so Focus Assist / Do Not Disturb can hide them. The red unread mark is the tray (notification area by the clock), not the taskbar pin.

Hide Notification Content (on by default for new installs) redacts sender and snippet in toasts and tray tooltips, and hides tray avatars.

What this app stores locally

Under the OS user-data folder: settings.json (preferences), optional product-update.json (update / later), optional main.log only if you enable verbose main-process logging, and crash notes only if you enable Save crash details. Chat history stays in the Chromium persist:main profile for messages.google.com — not uploaded by this wrapper.

Optional user.css in the same user-data folder (Settings → Load local user.css). Remote @import URLs are ignored.

Do not copy the Chromium persist:main profile folder to another PC or into a bug report — it holds your Messages session cookies. Work/Personal use persist:profile-work / persist:profile-personal. Guest is in-memory and is wiped on quit.

Certificate errors

This app never ignores a bad TLS certificate. If a host fails HTTPS, you see a local explanation page instead of Messages. Fix the clock, proxy, or TLS inspection, then restart the app.

Compose extras

Paste an image into the Messages compose box with the OS paste shortcut (Ctrl+V / Cmd+V); the web app attaches it when it allows paste. Drag a file onto the window when compose is focused. Settings can save three clipboard snippets and an optional signature appended only to sms:/tel: compose. Protocol links confirm before send when that setting is on.

Emoji: use the OS panel (Win+. on Windows, Control-Cmd-Space on macOS). This app does not ship a second picker.

Linux AppImage updates

Help → Check for Updates downloads the installer in your browser. Do not turn electron-updater auto-download back on for AppImage.

macOS Login Item

Settings → Start with the operating system uses a Login Item (app.setLoginItemSettings), not a LaunchAgent plist.

Linux systemd

Prefer the Settings autostart checkbox. A systemd user unit is an alternative only — see docs/SYSTEMD.md. Do not enable both.

Share

Unpackaged builds are not a Windows Share charm target. Use registered sms: / mms: handlers. See docs/WINDOWS_SHARE.md.
