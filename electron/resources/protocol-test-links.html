Protocol test links

Click a link to open Google Messages. Phone links start a new text; bare im: only focuses the app.

Open app (Instant Messaging)

  • im: — open / focus Google Messages
  • im:open — same, open only

Start a new text (sample number)

  • sms:+15555550100
  • smsto:+15555550100
  • tel:+15555550100
  • callto:+15555550100
  • im:+15555550100 — IM + compose

Notes

If Windows asks which app to use, pick Google Messages. Set defaults under Settings → Apps → Default apps. Replace the sample number with a real one when you want an actual conversation.
