# Feature: i18n

> Electron chrome (menus, Settings, native dialogs) follows the OS locale. Google Messages web keeps its own language. Do not copy `examples/` over the app.

## Acceptance criteria

- ✅ User-visible behavior: `es` / `es-*` OS locale shows Spanish Settings, File/Help/tray labels, and common dialogs
- ✅ Offline/error behavior: unknown locales and missing keys fall back to English
- ✅ Accessibility: same native menus; labels are translated strings
- ✅ i18n: English catalogs in `settingsCopy`, `menuCopy`, `aboutCopy`, `feedbackCopy`; overlay `catalogEs.ts`

## Smoke scenario

1. Given the OS locale is `en-US`
2. When the app starts
3. Then Settings still says Appearance
4. Given `es-MX`, when the app starts, Settings says Apariencia
